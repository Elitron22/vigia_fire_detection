# Datos, licencias y publicación

## Dataset

El dataset D-Fire no se incluye en esta entrega. El repositorio enlaza su fuente oficial y documenta las particiones utilizadas. Antes de publicar el proyecto, se debe conservar la referencia al autor y comprobar que el uso y redistribución respetan la licencia vigente indicada por la fuente.

## Pesos y resultados

Los pesos incluidos son resultado del entrenamiento del proyecto sobre D-Fire. El manifiesto registra su hash y procedencia experimental. No contienen el dataset original.

## Código

Esta copia no asigna automáticamente una licencia al código. Antes de hacer público el repositorio, el autor debe elegir una licencia compatible con las dependencias y con las condiciones del dataset. Si el acceso se limita a los tutores, debe comprobarse que ambos disponen de permiso y que el enlace funciona desde una sesión distinta.

## Dependencias

Las bibliotecas se instalan desde sus distribuidores oficiales y conservan sus propias licencias. Las versiones directas están fijadas en `requirements-app.txt` y `docker/requirements.txt`.

## Credenciales y privacidad

El token y el identificador de Telegram nunca deben subirse. El repositorio contiene solo `.env.example`, y `.env` está ignorado. Las imágenes o vídeos usados en una demostración pública deben revisarse para evitar datos personales o material sin permiso.
